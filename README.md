# Project 2 - Audio Processing

This repository contains the Python script and audio recordings used for processing audio signals and filtering out unwanted noise or artifacts.

## Repository Structure

* `audioProcessing.py`: The main Python script responsible for performing the audio processing pipeline.
* `diegoTijo.wav` & `juanMontoya.wav`: The original (base) audio recordings before processing.
* `diegoT_processed.wav` & `juanM_processed.wav`: The final clean audio files generated after processing and removing unwanted noise/garbage.
